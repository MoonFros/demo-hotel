# Topmax Executive Hotel & Suites

A responsive React + Tailwind accommodation website for Topmax Executive Hotel & Suites in BDPA, near the University of Benin, Benin City.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build` and preview it with `npm run preview`.

## Property details and imagery

Update `src/config/site.js` with verified contact channels and social links before launch. The precise street address and hotel map pin have not been supplied, so the map and address currently identify the BDPA area only.

The images in `public/images/` are realistic illustrative placeholders, not photographs of Topmax. Replace them with approved exterior, reception and room photos when available. Room names, amenities and prices remain unlisted until supplied by the hotel.

## Enquiries

The booking form routes to the configured WhatsApp number or email address. Until a channel is configured, it clearly indicates that nothing has been sent and lets visitors copy their enquiry. It does not claim live availability or confirm a booking.
