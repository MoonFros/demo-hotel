# Topmax Executive Hotel & Suites

A responsive React + Tailwind landing page for Topmax Executive Hotel & Suites in BDPA, near the University of Benin, Benin City.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build` and preview it with `npm run preview`.

## Hotel information and enquiries

Update `src/config/site.js` with verified contact channels and social links before launch. The website intentionally leaves unknown details blank: it does not invent room types, amenities, rates, reviews, or contact information. Photography is illustrative and labelled as such; the map shows the BDPA area, not a verified hotel pin.

Booking and contact forms route to a configured WhatsApp number or email address. Until one is configured, submissions are not transmitted; the page clearly says so and lets visitors copy the prepared enquiry.
